\section{メモ}
\begin{verbatim}
reveal は動詞で、
・明らかにする
・暴露する
・公開する
・秘密を打ち明ける

nc
Netcat。サーバーと直接通信するためのコマンド。

mysterious-sea.picoctf.net
接続先サーバー名。

64561
接続先ポート番号。

つまり日本語では、
picoCTF が用意したリモートサーバーの 64561 番窓口に接続する
\end{verbatim}
